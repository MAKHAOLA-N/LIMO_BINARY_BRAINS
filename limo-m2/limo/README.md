# LIMO — Binary Brains

A Sesotho-language processor derived from RISC-V, and a browser simulator for it.
CS3520 Computer Organisation and Architecture, National University of Lesotho.

**Live site:** _(GitHub Pages link)_

## Run it

- **Simulator:** open `index.html` in any browser. No install needed.
- **Tests:** `node tests/run.js`

## Folders

| Folder | Contents |
| --- | --- |
| `src/` | Assembler, page logic, styles, pipeline data model |
| `tests/` | Assembler unit tests |
| `examples/` | Sample `.limo` programs |
| `docs/` | ISA specification (M1), simulator design and sprint note (M2) |
